A one-line entry for the make.fun "One Star for Monday" bounty: a Python
program that writes a single one-star review — of Monday, written as if
Monday were a restaurant — to `/output/entry.txt`.

The special arrived uninvited at 6am. The order of five more minutes
never came. And the bill was eight meetings.

Run it with `python3 main.py` (set `MAKEFUN_OUTPUT_DIR` to change where
`entry.txt` lands).
